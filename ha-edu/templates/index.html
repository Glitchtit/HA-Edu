Skapa ny instans

Om du anger det kan detta lösenord användas för att starta om instansen. Adminlösenordet fungerar också.

Lås upp adminfunktioner

Ange adminlösenordet för att visa administrationskontroller.

Nollställ instans

Ange lösenord för att nollställa till standard HA-avbildning.

Varning: Detta kommer att radera all data och alla konfigurationer för denna instans!

ℹ️ Lösenordsalternativ:
  • Använd instanslösenordet (om det angavs när instansen skapades)
  • Eller använd adminlösenordet (om det är konfigurerat)

Ta bort instans

Ange lösenord för att ta bort .

Varning: Detta kommer att permanent ta bort instansen och all dess data!

ℹ️ Lösenordsalternativ:
  • Använd instanslösenordet (om det angavs när instansen skapades)
  • Eller använd adminlösenordet (om det är konfigurerat)

Ta bort alla instanser

Ange adminlösenord för att ta bort alla instanser.

Varning: Detta kommer att permanent ta bort ALLA instanser och all deras data!

Växla instansskapande

Ange adminlösenord för att instansskapande.

Lägg till läraråtkomst

Ange adminlösenord för att lägga till läraråtkomst till .

Vad gör detta?
  • Skapar ett sekundärt adminkonto för läraren ()
  • Studentens konto och data förblir oförändrade
  • Låter läraren övervaka studentens framsteg
  • Kan endast användas efter att studenten slutfört onboarding

Starta om instans

Ange lösenord för att starta om .

ℹ️ Lösenordsalternativ:
  • Använd instanslösenordet (om det angavs när instansen skapades)
  • Eller använd adminlösenordet (om det är konfigurerat)

Lägg till läraråtkomst på alla instanser

Ange adminlösenord för att lägga till läraråtkomst till alla instanser.

Vad gör detta?
  • Skapar ett läraradminkonto () på varje instans
  • Hoppar över instanser som inte slutfört onboarding
  • Studentkonton och data förblir oförändrade
  • Instanser startas om automatiskt för att tillämpa ändringarna

Starta alla instanser

Ange adminlösenord för att starta alla instanser.

ℹ️ Information:
  • Startar alla stoppade instanser
  • Instanser som redan körs påverkas inte

Stoppa alla instanser

Ange adminlösenord för att stoppa alla instanser.

⚠️ Varning:
  • Stoppar alla körande instanser
  • Användare kommer att förlora anslutningen till sina instanser
  • Data bevaras - instanserna kan startas igen
